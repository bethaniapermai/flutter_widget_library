# Dynamic UI Widget Component Library

A Flutter application showcasing a reusable UI component library with authentication, built using Dart and Flutter.

## Features

- Splash screen with session check
- Login with SharedPreferences session management
- Dashboard with component overview
- **Button Components** – 4 variants (Filled, Outlined, Text, Danger) with loading state
- **Card Components** – Basic, Stat, Action variants
- **Graph Components** – Animated bar charts with custom colors
- Logout with session clearing

## Tech Stack

- Flutter & Dart
- SharedPreferences (local session)
- Material Design 3
- Custom design system & theming
